# Streamlit Alumnos 🎓📊

This project was developed as part of my learning process in data analysis and Python programming. The goal was to create a simple and interactive web application using **Streamlit** to visualize and explore student data.

---

## 🛠️ Technologies and Tools Used

- **Python**
- **Pandas**
- **Streamlit**
- **VS Code / Jupyter Notebook**
- **Git & GitHub**

---

## 📌 What I Practiced and Learned

- Loading and manipulating tabular data using **Pandas**.
- Creating an interactive app with **Streamlit**.
- Implementing widgets like `selectbox`, `checkbox`, and `multiselect` for dynamic filtering.
- Applying basic data cleaning and transformation techniques.
- Grouping and summarizing data with `groupby` and aggregation functions.
- Displaying tables and key metrics using `st.dataframe()` and `st.metric()`.
- Writing clean and organized code to improve readability and maintainability.
- Publishing projects on **GitHub** and writing clear documentation.

---

## 📈 App Features

- Filter student records by **subject** and **attendance**.
- View statistics such as average grades, number of students per subject, and pass rates.
- Clean, responsive layout using Streamlit’s layout options.
- Real-time updates based on user interaction.
